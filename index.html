04

Automation

Phone App එක වහලා තිබුණත් ESP boards online නම් automation වැඩ කරයි.

AUTO MODE කියන්නේ මොකක්ද?

Schedules සහ automatic functions enable/disable කරන main control එක. Manual ON/OFF controls වෙනම භාවිත කරන්න පුළුවන්.

Schedules

Output 1, Output 2 හෝ Output 3 සඳහා one-time හෝ recurring ON/OFF schedule හදන්න පුළුවන්.

Countdown

Output එක තෝරලා මිනිත්තු ගණනක් දාලා ඒ කාලය අවසානයේ ON/OFF action එකක් run කරන්න පුළුවන්.

Auto-off

Output එක ON වුණාට පස්සේ set කරපු කාලය ගියාම automatically OFF කරන්න පුළුවන්.

Scenes

Outputs කිහිපයක් එකවර වෙනස් කරන්න. උදාහරණයක් විදිහට All ON, All OFF හෝ Night Scene.

05

Setup කරන Steps

Project එක මුලින් setup කරනකොට මේ order එක follow කරන්න.

  1. 1
    ESP32 firmware එක upload කරන්න

    Wi-Fi Name සහ Password code එකට දාලා ESP32-CAM/ESP32 board එකට firmware upload කරන්න.

  2. 2
    ESP32 IP එක බලන්න

    Serial Monitor එක 115200 baud වල open කරලා ESP32 එකට ලැබුණු IP address එක note කරගන්න.

  3. 3
    ESP8266 bridge firmware එක update කරන්න

    ESP8266 code එකේ ESP32 IP එක හරිද බලලා firmware එක upload කරන්න.

  4. 4
    iPhone App එක install කරන්න

    GitHub Actions හරහා IPA build කරලා ඔබගේ signing method එකෙන් iPhone එකට install කරන්න.

  5. 5
    Outputs තුනම test කරන්න

    Automation දාන්න කලින් Output 1, Output 2 සහ Output 3 ON/OFF individually test කරන්න.

07

ප්‍රශ්න සහ ඉක්මන් විසඳුම්

Project එකේ common errors කිහිපයක්.

App එකේ Output 3 OFFLINE කියලා පෙන්වනවා

ESP32 Wi-Fi එකට connect වෙලාද බලන්න. ESP8266 සහ ESP32 එකම local network එකේද, ESP32 IP එක ESP8266 firmware එකේ හරිද කියලා check කරන්න.

Output 3 ON/OFF reverse වෙලා

මේ setup එකේ GPIO13 සඳහා HIGH = ON සහ LOW = OFF භාවිත කරන්න.

OTA upload එකේ “No response from the ESP”

Arduino IDE එකේ selected Network Port එක ESP32 එකේ current IP එකට match වෙනවද බලන්න. අවශ්‍ය නම් USB adapter එකෙන් wired upload එකක් කරන්න.

GitHub build එක ScheduleTests වල fail වෙනවා

Test file එකේ intentional fatalError(...) line එකක් තිබේද බලලා valid test assertion එකකට මාරු කරන්න.

ESP32 Wi-Fi එකට connect වෙන්නේ නැහැ

Wi-Fi SSID සහ Password exact ද බලන්න. ESP32 සඳහා 2.4 GHz Wi-Fi භාවිත කරන්න.

Safety

Testing කරනකොට controller side එක low-voltage වලින් කරන්න. මේ page එක mains AC wiring guide එකක් නෙවෙයි. Relay module එකක් සහ external load එකක් භාවිත කරනවා නම් ඒවාට ගැළපෙන isolation, ratings සහ ආරක්ෂිත wiring අවශ්‍යයි.
